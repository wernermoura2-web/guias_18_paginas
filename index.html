Guardar e continuar

Use Salvar arquivo para baixar o JSON. Para continuar, entre no mesmo modo de uso e abra o JSON salvo. No trabalho em equipe, use Importar processos para incorporar apenas os processos escolhidos.

Os rascunhos locais dos dois modos são separados. Para levar dados de um modo ao outro, use o JSON. A página inicial pode ser adicionada à tela inicial do celular pelo menu do Chrome. Abra pelo endereço do site, começando com https://.

O preenchimento não é enviado automaticamente ao GitHub ou ao Supabase. Guarde cópias dos JSONs fora do navegador.
